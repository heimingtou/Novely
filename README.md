# Novely

Trang đọc truyện chữ: `/novels/demo` → chọn chương hoặc **Đọc từ đầu**.

Xem [hướng dẫn Trang đọc](docs/reading-page.md) để chạy thử, kiểm thử và tìm hiểu phạm vi lưu dữ liệu trên trình duyệt.

Giao diện sáng/tối: mở menu ảnh đại diện → **Chế độ tối**. Xem [hướng dẫn giao diện](docs/theme.md).

Tiếng Việt / English: mở menu ảnh đại diện → **Ngôn ngữ**. Xem [quy ước tên tính năng và bản dịch](docs/languages.md).

Cộng đồng đọc truyện: `/forum` — xem [hướng dẫn Forum](docs/forum.md) cho mô tả chức năng, dữ liệu demo và kiểm thử.
