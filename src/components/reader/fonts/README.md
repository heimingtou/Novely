# Noto Serif

- Nguồn: https://github.com/google/fonts/tree/main/ofl/notoserif
- File gốc: `NotoSerif[wdth,wght].ttf` (variable font, kiểu normal).
- Giấy phép: SIL Open Font License 1.1, xem `OFL.txt` đi kèm.
- Tải ngày 21/10/2026; file được giữ nguyên nội dung, chỉ đổi tên thành `NotoSerif-Variable.ttf`.

Font được phục vụ nội bộ qua `next/font/local`, có đủ bộ ký tự tiếng Việt. Lựa chọn `serif` dùng font này thay Georgia hệ thống, đồng thời giữ nguyên khóa thiết lập cũ và dữ liệu vị trí/ghi chú đã lưu.

## Các font bổ sung

- `BeVietnamPro-Regular.ttf`: bản normal 400 từ https://github.com/google/fonts/tree/main/ofl/bevietnampro, giấy phép trong `BeVietnamPro-OFL.txt`.
- `Montserrat-Variable.ttf`: bản normal 100–900, đổi tên từ `Montserrat[wght].ttf` tại https://github.com/google/fonts/tree/main/ofl/montserrat, giấy phép trong `Montserrat-OFL.txt`.
- Hai font trên được tải ngày 21/10/2026, giữ nguyên nội dung và phục vụ qua `next/font/local`.
- Palatino, Arial, Times New Roman và Bookerly dùng font trên thiết bị. Không phân phối file Bookerly trong dự án; khi không có Bookerly, lựa chọn này dùng Noto Serif và giao diện báo rõ.
